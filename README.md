# Willy Werkel Fix

A one-click installer that makes **Autos bauen mit Willy Werkel** (English: **Gary Gadget: Building Cars**) run on modern **Windows 10 & 11**.

🎮 Game disc image (ISO): **https://archive.org/details/autos-bauen**

---

## How to install (English)

1. Download **`WillyWerkel-Setup.exe`** from the [**Releases**](../../releases) page.
2. Download the game from **https://archive.org/details/autos-bauen** (the `.iso` file).
3. Double-click **`WillyWerkel-Setup.exe`**.
   - If a blue Windows box appears, click **More info → Run anyway**.
   - Click **Yes** if Windows asks for permission.
4. When asked, pick the **`.iso` file** you downloaded.
5. When asked where to install, just click **Select Folder**.
6. Wait a moment, then start the game from the new **Autos bauen mit Willy Werkel** icon on your desktop.

💡 To quit the game, press **Alt + F4**.

---

## Installation (Deutsch)

1. Lade **`WillyWerkel-Setup.exe`** von der [**Releases**](../../releases)-Seite herunter.
2. Lade das Spiel von **https://archive.org/details/autos-bauen** herunter (die `.iso`-Datei).
3. Doppelklicke **`WillyWerkel-Setup.exe`**.
   - Falls ein blaues Windows-Fenster erscheint: **Weitere Informationen → Trotzdem ausführen**.
   - Bei der Sicherheitsabfrage auf **Ja** klicken.
4. Wähle die heruntergeladene **`.iso`-Datei** aus.
5. Beim Installationsort einfach auf **Ordner auswählen** klicken.
6. Kurz warten, dann das Spiel über das neue Desktop-Symbol **Autos bauen mit Willy Werkel** starten.

💡 Zum Beenden **Alt + F4** drücken.
